## 〇、两阶段绘图工作流（不指望一次生成就完美）

**核心思想**：物理图很难一次画准，把"画出图"和"画对图"拆成两个阶段，各解决一件事——
- **阶段一 · 文生图生成草图**（解决"有没有"）
- **阶段二 · 图编辑局部精修**（解决"准不准"）

### 阶段一：文生图生成草图（解决"有没有"）

按考点从下方"领域专属绘图 Prompt 模板"选对应模板，作为**文生图模型**的 prompt，
先产出一张包含全部物理要素的草图。

此阶段只求**要素齐全、结构正确**，明确允许不完美：
- 物体、力箭头、坐标轴、标注符号都在场，一个不缺
- 结构关系对（物体在斜面上、弹簧连着墙、电路连通、光从空气入玻璃）
- **不追求**：箭头位置精确、标注文字无误、线条粗细统一

**阶段一验收**：要素齐全 + 结构正确即通过，进入阶段二。

### 阶段二：图编辑局部精修（解决"准不准"）

把草图交给**图编辑模型**（能"看图改图"的多模态模型），针对最常见的三类缺陷做局部精修：

1. **调整箭头位置与方向**——力/速度箭头必须从物体质心或作用点正确引出，
   方向严格符合物理规律（重力竖直向下、支持力垂直于接触面、摩擦力沿接触面）。
2. **修正标注文字**——中文标签用宋体，物理量符号用斜体（$F$、$m$、$v$），
   单位用正体（m/s²、N、V），字号统一比正文小一号，纠正错别字与符号。
3. **统一线条粗细**——全部线条统一为细线（约 0.6–1pt），去除彩色与填充，
   保持黑白线稿风格。

**阶段二精修 Prompt 模板**（可直接套用，替换方括号内容）：

```
请对这张物理示意图做局部精修，保持整体布局与物理内容不变，只修正以下三类细节：
1. 调整箭头位置：所有力/速度箭头必须从物体【木块/小球/小车】的质心或作用点引出，
   方向严格符合物理规律（重力竖直向下、支持力垂直于接触面、摩擦力沿接触面）。
2. 修正标注文字：中文标签统一用宋体，物理量符号用斜体（如 F、m、v、F_N），
   单位用正体（如 m/s²、N、V），字号统一比正文小一号，纠正错别字。
3. 统一线条粗细：所有线条统一为细线（约0.6–1pt），去除彩色与填充，保持黑白线稿。
其余部分保持不变，输出精修后的完整图。
```

**精修验收清单**（阶段二完成后逐项核对）：
- [ ] 所有力/速度箭头从质心或作用点正确引出，方向符合物理规律
- [ ] 标注文字清晰、正确，字体/字号统一，无错别字
- [ ] 线条粗细一致，黑白线稿风格，无彩色/填充残留
- [ ] 与整套试卷其他图风格一致（看整体，不只单张）

**无图编辑模型时的等价做法**：
- 用 TikZ / matplotlib 时：阶段一模板对应一段绘制代码，"阶段二"即对代码做 review——
  检查箭头起点是否在质心、文字是否 `\small`/`fontsize` 统一、线宽是否一致，然后修正坐标重绘。
- 用多模态视觉模型（如 Claude）时：先让它看草图并列出"需要修正的位置清单"
  （哪个箭头方向错了、哪处文字笔误、哪条线偏粗），再按清单重绘或精修。
- 一条经验：**阶段二宁可多跑一轮**。物理图细节决定教学正确性，箭头方向错了学生直接做错题。

### 绘图工具选择总则

| 场景 | 工具 |
|------|------|
| 有文生图模型 + 有图编辑模型 | 阶段一用模板 prompt 生草图 → 阶段二用图编辑 prompt 精修 |
| 只有多模态视觉模型（Claude 等） | 阶段一让模型"画一幅草图"，阶段二让它自查修正清单后重绘 |
| 无图像模型（纯代码出图） | 用 TikZ / matplotlib，阶段二 = 代码 review + 坐标修正 |
| LaTeX 试卷最终版 | TikZ 优先（矢量、可精确控制、与正文同字体），matplotlib 兜底 |

## 一、通用绘图方法（所有物理图都必须遵守，阶段二精修依据）

### 1. 总体风格（从真题图归纳）

- **黑白矢量线条**：纯黑线条 + 纯白（或透明）背景，**不用彩色填充**。真题图几乎全部是
  黑色线稿，可有 1 处淡灰底（如表示"匀强磁场区域""地面/墙面"）。
- **线条细且均匀**：正文配图线宽相当于 PDF 中 0.6–1 pt（TikZ `line width=0.5pt~1pt`），
  不要用粗描边。示意"地面""墙面""支架"等支撑物用**斜纹填充**或**粗短线簇**。
- **字体**：图上文字用中文宋体/黑体（小五~五号），物理量符号用斜体拉丁字母
  （`$v$`, `$F$`, `$m$`），单位用正体（`m/s²`）。字号比正文小一号，不能比正文大。
- **无装饰**：不加阴影、渐变、3D 立体效果、照片质感。真题图是"教科书式"平面示意图。
- **留白紧凑**：图形占题面宽度一半左右，垂直方向按需，不要整版空白。

### 2. 元素规范

| 元素 | 画法 |
|------|------|
| 物体（木块/小车/小球） | 规则矩形/圆/三角形，单色细描边，内可写 `$m$` |
| 地面/桌面/斜面 | 粗直线；接触面处画**细斜纹簇**（表示粗糙）或空（光滑） |
| 墙面/支架 | 竖直粗线 + 斜纹填充 |
| 弹簧 | 连续锯齿折线（约 6–8 个齿），两端直线 |
| 轻绳/轻杆 | 细直线；绳可画轻微下垂弧度 |
| 滑轮 | 小圆 + 中心小叉或实心小圆；绳跨过轮缘 |
| 力/速度/加速度箭头 | `->` 实心小箭头，箭头长度表示大小比例，箭头头小而尖 |
| 虚线 | 表示辅助线、延长线、法线、轨迹参考、平衡位置、光路虚线 |
| 坐标轴 | 细线 + 末端箭头；轴名写在箭头外侧：横轴 `t/s`、`x/m`，纵轴 `v/(m·s⁻¹)` 等 |
| 图像曲线 | 平滑曲线（直线/抛物线/正弦波），关键点用小圆点并标注字母 |
| 电路 | 规范电路符号：电源 `-|`、电阻 `──▭──`、开关、电流表/电压表圆圈内 A/V |
| 磁场/电场 | 细曲线带箭头（电场线/磁感线），区域用淡灰底 + 外框 + `B` / `E` 标注 |
| 角度 | 圆心小圆弧 + `θ` 标注，或直接标度数 |
| 刻度 | 坐标轴刻度短线 + 数值，单位统一在轴名括号内 |

### 3. 坐标与图像类图（v-t、x-t、a-t、F-t、U-I、p-V 等）规范

- 轴线用箭头，**标注物理量与单位**，如 `t/s`、`v/(m·s⁻¹)`、`U/V`。
- 横纵轴比例协调：斜线约 30°–50° 倾角为宜，避免过陡/过平。
- 图线特征点（转折点、交点、峰值）用实心小圆点，旁边标 `A、B、C` 或时刻 `t₁`。
- 需要比较两条线时，一实线一虚线，加图例或在线上标注 `①②`。
- 网格线可有可无，真题常无网格（干净），少量坐标刻度即可。

### 4. 力学情境图规范

- 物体通常画**侧视图**矩形；多个物体并排/叠放，标注质量 `$m$`、`$M$` 或 `$m_1$`、`$m_2$`。
- 力箭头从**物体质心**引出，方向准确（重力竖直向下、支持力垂直接触面、摩擦力沿接触面）。
- 标注运动方向（大箭头 `v`）与位移（`x`、`Δx`）。
- 斜面：画斜面直线，标注倾角 `θ`，物体放斜面上，虚线标注高度 `h`。
- 曲线轨道、传送带、圆弧轨道：用光滑曲线 + 物体 + 圆心 `O` + 半径 `r`。

### 5. 电路图规范

- 电源：长竖线（正极）+ 短粗竖线（负极），标注 `E`、`r`。
- 电阻：空心矩形（`▭`），标注 `R`、`R₁`。
- 电流表 A、电压表 V：圆圈内字母。
- 滑动变阻器：矩形带滑片箭头或锯齿式，标注 `R_p`。
- 开关：断开/闭合两种，闭合为一条直线接通。
- 导线用直线直角连接，横平竖直。
- 交变电流/发电机：电源符号内画 `~` 或波形。

### 6. 光学图规范

- 入射光线/折射光线/反射光线：直线 + 箭头，入射方向明确。
- 法线：**虚线**过入射点垂直于界面。
- 界面：粗直线，两侧标介质名（"空气""玻璃""水"）。
- 透镜：中间厚凸/中间薄凹的透镜符号 + 光轴虚线；焦点 `F`、两倍焦距 `2F`、光心 `O`。
- 角度：入射角/折射角用圆弧标 `θ₁`、`θ₂` 或度数。
- 全反射：只画反射光，标注临界角 `C`。

### 7. 电磁场图规范

- 匀强磁场区域：淡灰矩形/圆 + 外框 + `B`；带电粒子轨迹用实线（圆弧），区域外直线。
- 匀强电场：两平行极板（粗横线）+ 竖直均匀电场线（带箭头）+ `E`、两极板 `+ −`。
- 电场线：从正电荷出发、终止于负电荷的曲线，带箭头；点电荷用小圆 + `+`/`−`。
- 磁感线/磁场方向：`×`（垂直纸面向里）、`·`（向外）符号标注在区域内。
- 安培力/洛伦兹力方向：按左手定则画出并标注。

## 二、阶段一绘图 Prompt 模板（文生图生成草图用）

> 使用方式：选与考点匹配的模板 → 作为文生图模型的 prompt 生成**草图** →
> 再按"〇、阶段二"精修。这些模板已内置真题风格，但**不要指望一次到位**，
> 草图通常需要阶段二修正箭头/文字/线宽。

### 模板 1：受力分析图

```
请绘制一张上海高中物理试题风格的受力分析图（黑白线稿，无填充，细线）：
- 画面为【斜面/水平地面/悬挂/竖直墙壁】上的物体【木块/小球/箱子】，
  物体画成矩形/圆形，内部标注 m。
- 从物体质心画出所有力的箭头：重力 G=mg（竖直向下）、支持力 N（垂直于接触面）、
  摩擦力 f（沿接触面，注明方向）、拉力/推力 F（沿绳/推力方向）。
- 力箭头为实心细箭头，按真实大小比例，标注 F、G、N、f 字母。
- 若在斜面上，画出斜面直线、标出倾角 θ、用虚线标注高度 h。
- 坐标参考：竖直方向、水平方向（或用虚线标出斜面方向与垂直斜面方向）。
- 不要网格、不要彩色、不要背景。图上文字用中文标签 + 物理量符号。
```

### 模板 2：运动学图像（v-t / x-t / a-t / F-t）

```
请绘制一张上海物理试题风格的 v-t 图像（黑白线稿）：
- 建立坐标轴：横轴 t/s，纵轴 v/(m·s⁻¹)，两轴末端带箭头。
- 画一条【匀变速直线运动】的图线：从 (0, v₀) 开始的一段倾斜直线，
  斜率代表加速度 a，标注关键点 t₁、t₂ 处的速度值。
- 在曲线转折处画实心圆点并标注 A、B、C（或 t₁、t₂）。
- 若有第二条图线（比较运动），用虚线表示，并在图例位置标 ①②。
- 坐标刻度只标主要数值，图面干净无网格。
- 图上文字：轴名、单位、图线标注，全部使用中文标签与物理量符号。
```

### 模板 3：平抛 / 抛体运动示意图

```
请绘制一张上海物理试题风格的平抛运动示意图（黑白线稿）：
- 水平地面为底线（可画斜纹表示粗糙），左侧高处有一水平抛出点 O。
- 从 O 点画水平初速度箭头 v₀，随后一条平滑抛物线轨迹（虚线辅助延伸）。
- 轨迹上取 2-3 个特征位置点，标注 A、B、C 和对应位移 x、y。
- 在某一时刻画出速度分解：水平分速度 vx（虚线箭头）、竖直分速度 vy（虚线箭头），
  合成速度 v 用实线箭头，并画出该点与抛出点的水平距离 x、竖直距离 y（用虚线标出）。
- 无彩色、无网格。标注高度 h、水平射程 x 等关键量。
```

### 模板 4：圆周运动 / 过桥 / 转弯

```
请绘制一张上海物理试题风格的圆周运动示意图（黑白线稿）：
- 画一段圆弧轨道（如拱形桥顶部、凸桥、凹桥），标注圆心 O、半径 r（虚线）。
- 小车/小球在轨道某位置，画重力和支持力/弹力箭头，标注 v、F_N。
- 或画水平面内转弯（汽车转弯）：画出轨迹圆（俯视或侧视），标注向心力来源。
- 关键：速度方向沿切线，用箭头标注；向心方向指向圆心。
- 简洁线稿，标注质量 m、半径 r、速度 v。
```

### 模板 5：斜面 + 传送带

```
请绘制一张上海物理试题风格的传送带示意图（黑白线稿）：
- 两条平行线构成传送带（上下带面），两端各一个圆滑轮。
- 带面上放一个木块 m，画出传送带运动方向箭头 v、木块相对滑动时摩擦力方向 f。
- 若为倾斜传送带：带面与水平成 θ 角，标出倾角，木块受力画全。
- 标注带长 L、倾角 θ、初速度 v₀。
- 线条简洁，无彩色，关键量全部用符号标注。
```

### 模板 6：连接体 / 滑轮系统

```
请绘制一张上海物理试题风格的滑轮系统示意图（黑白线稿）：
- 一个定滑轮（顶梁下方的小圆），细绳跨过滑轮。
- 绳子两端分别挂物体 m₁、m₂（矩形/圆），质量标注清楚。
- 若动滑轮：画出滑轮下方挂的物体 M，绳绕过动滑轮两端固定或连接 m。
- 画出物体运动方向箭头 v、加速度方向 a，标注绳张力 T。
- 桌面/地面接触处按光滑或粗糙（斜纹）标注。
- 简洁黑白线稿。
```

### 模板 7：弹簧振子 / 简谐运动

```
请绘制一张上海物理试题风格的弹簧振子示意图（黑白线稿）：
- 左端墙面（粗线 + 斜纹填充），弹簧（锯齿折线）连接一个木块 m 放在水平面上。
- 画出平衡位置虚线（红色或灰色虚线均可，但建议统一用虚线标出）。
- 标注振幅 A、位移 x、弹簧劲度系数 k、质量 m。
- 或画竖直悬挂：天花板下弹簧吊小球，标注平衡位置、拉伸/压缩量。
- 简洁线稿，不填充。
```

### 模板 8：单摆

```
请绘制一张上海物理试题风格的单摆示意图（黑白线稿）：
- 天花板上一点 O（悬挂点），细线下挂小球（圆），标出摆长 l（细线到球心）。
- 小球偏离平衡位置，画最大偏角位置与平衡位置两条线（虚线平衡位），标出角度 θ。
- 标注振幅 A、摆长 l、角度 θ、小球质量 m，重力方向箭头 mg。
- 简洁黑白线稿。
```

### 模板 9：电路图

```
请绘制一张上海物理试题风格的电路图（黑白线稿，横平竖直）：
- 电路元件：【电源 E（长竖线+短粗线，标注 E、内阻 r）/ 电阻 R（空心矩形）/
  电流表 A（圆圈内 A）/ 电压表 V（圆圈内 V）/ 开关 S / 滑动变阻器】，
  按串联或并联连接。
- 导线用直线、直角拐弯，元件布局横平竖直。
- 标注各元件符号与电阻值、电流 I、电压 U、电源电动势 E。
- 如果是测量电路，标明"电压表并联在电阻两端、电流表串联在干路"。
- 简洁线稿，无彩色填充。
```

### 模板 10：带电粒子在磁场中的圆周运动

```
请绘制一张上海物理试题风格的带电粒子在匀强磁场中运动示意图（黑白线稿）：
- 磁场区域：矩形或圆形区域用淡灰底 + 外框，标注 B（磁场方向，可用 × 表示垂直纸面向里）。
- 粒子轨迹：进入区域前一段直线（速度 v，带箭头），进入后画一段圆弧（实线），
  出区域后再一段直线。
- 标注圆心 O（圆弧对应圆心，可用虚线画半径 r）、回旋半径 r、速度 v、偏转方向。
- 标注粒子的电性（正/负）与偏转方向关系。
- 关键几何：入射速度方向、出射速度方向、圆弧对应圆心角。
```

**配图总体原则**：
1. **两阶段流程**：先按模板生成草图（要素齐全、结构正确即可），再用图编辑模型精修
   （箭头位置 → 标注文字 → 线条粗细），按精修验收清单逐项核对。
2. 一题一图，图为题服务；图像要能独立表达题意，学生不依赖文字也能理解。
3. 图与答案分离：作答区如需画图，出题时给出"示意图"，答案区给出"标准图"。
4. 所有图保持统一风格（黑白线稿、细线、中文标签、物理量符号），一套卷风格一致。
